PIGFACE 简体中文汉化补丁  v1.8
Steam 正版 / Windows / 纯单机
更新与反馈：https://github.com/box-26/PIGFACE-zh


一、这是什么

Steam 版《PIGFACE》的中文补丁。装好后菜单、选项、任务目
标、对白、便条、手机、商店、制作站都显示中文。

游戏本体一个字节都不改：只新增一个 BepInEx 文件夹，文字、
字体和一张“售罄”贴图在运行时于内存替换，卸载即还原。


二、安装

1. 解压到任意位置（不要在压缩包里直接双击）。
2. 双击“安装汉化.bat”。
3. 脚本自动找游戏，找不到才让你粘贴路径。
4. 看到“安装成功”就好，之后从 Steam 正常启动。

装在 C:\Program Files 这类目录会一闪而过：右键“安装汉化.
bat”，选“以管理员身份运行”。

升级：解压新包、再双击一次，就地覆盖，不用先卸载。存档、
按键设置、云同步都不受影响；检测到别人的 Mod 会停下。


三、卸载

双击“卸载汉化.bat”。文件移到
%TEMP%\PIGFACE_CN_removed_<时间>，不硬删，确认正常后自行删
除。本体从未被改，没有残留。


四、用起来会遇到的

1) 中文晚一步出现（正常）
   第一眼常是英文，0.2～1 秒后变中文，新开面板约 0.35 秒。
   等 2 秒还是英文，才算是漏词。

2) 漏词与反馈
   双击“检查缺词.bat”，会生成“缺词报告.txt”，发到 Issues
   即可。报告里有系统、版本、字体和漏掉的原文，不含用户名
   和路径；有截图更好。只有打不开或闪退才需要 LogOutput.log。

3) 杀毒软件报毒
   winhttp.dll 是 BepInEx 的注入器，Mod 圈通用做法，行为像
   木马所以常被误报。加白名单，或从隔离区“恢复并信任”。
   最坏是文件被删、退回英文，不坏档、不崩。

4) 已经装过别的 Mod
   是本汉化：就地更新。是别人的：安装会停下，不覆盖。
   想共存：把 plugins\PigfaceCN 手动放进
   现有的 BepInEx\plugins。

5) 权限
   没写权限（Program Files 等）：按第二节用管理员运行。

6) 游戏更新 / 验证完整性
   更新后补丁还在。小更新照常用，新句子显示英文；大更新
   （换引擎 / IL2CPP）可能整体失效。
   验证完整性不影响，验完照样中文。

7) 会不会封号
   不会。纯单机，无 EAC / BattlEye / VAC，不改 exe 与资源包。
   存档不动，仍在 LocalLow\titolovesyou\PIGFACE\，与英文版
   共用同一个档。

8) 装了还是英文 / 出方块
   先看 BepInEx\LogOutput.log 有没有这几行：
     dict loaded: 987 entries
     font: simhei.ttf
     harmony patched ok
   没有日志：注入没成功，多半被杀软删了 winhttp.dll。
   font: NONE：没找到中文字体，把 font.ttf 放回去。
   方块 = 字体没加载；超框或断行难看 = 中英长度差异，属已知
   瑕疵，可在词库手动加换行。

9) 低分辨率下文字发虚
   原版如此：字号不变，但屏幕像素少了，每个字分到的像素变
   少，笔画糊在一起。调回 1920×1080 或更高即可。

10) 系统
   已验证：Win11 23H2 实机、Win10 64 位虚拟机。
   只依赖游戏自带 Mono，不用另装 .NET / VC++。
   Win7 与 32 位系统游戏本身不支持；Linux / Steam Deck 未验
   证；路径含中文未实测，没反应就换英文路径。
