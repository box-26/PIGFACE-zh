一、这是什么
----------------------------------------------------------------
给 Steam 游戏《PIGFACE》用的中文补丁。装好之后，菜单、选项、
任务目标、对白、便条、手机、商店与制作站的文字都会变成中文。

它不改游戏本体：不改 exe、不改 data.unity3d、不改任何 dll。
安装只是在游戏目录里新增 BepInEx 文件夹；文字、字体和一张
“售罄”贴图都是运行时在内存里替换的，卸载后完全恢复原状。


二、安装
----------------------------------------------------------------
  1. 解压压缩包到任意位置（桌面就行，别在压缩包里直接双击）。
  2. 双击「安装汉化.bat」。
  3. 程序自动找 Steam 库里的 PIGFACE；找不到时让你粘贴路径
     （Steam 库里右键游戏 → 管理 → 浏览本地文件，复制地址栏）。
  4. 看到“安装成功”即完成，以后从 Steam 正常启动游戏。

  装在 C:\Program Files 这类目录时双击会一闪而过，
  改成右键「安装汉化.bat」→ 以管理员身份运行。

  已经装过旧版补丁，怎么升级？
  直接把新包解压，重新双击「安装汉化.bat」即可，不用先卸载。
  脚本检测到目录里装的是本补丁（plugins\PigfaceCN）就就地覆盖；
  存档、按键设置、Steam 云同步都不受影响。
  只有当目录里是“别人的 Mod”时才会停下，不覆盖、不混合。


三、卸载
----------------------------------------------------------------
  双击「卸载汉化.bat」即可。补丁文件会被移到
  %TEMP%\PIGFACE_CN_removed_<时间>，不会硬删，确认游戏正常后
  自己删掉那个文件夹就行。游戏本体从未被修改，不存在残留。


四、使用中的各种情况
----------------------------------------------------------------
1) 中文会“晚一步”出现，这是正常的
   补丁只能在运行时替换文字，所以第一眼常是英文，零点几秒后
   变中文：启动时约 0.2～1 秒；新开商店/制作站/手机等界面约
   0.35 秒；切关卡、读盘、改分辨率时会再来一次。手机面板由
   游戏每帧重写，个别数值轻微跳动，属已知现象。
   ★ 等 2 秒仍是英文，才算漏词 → 用「检查缺词.bat」列出来。

2) 系统与环境
   · Windows 11：已验证。
   · Windows 10 64 位：判断可用（BepInEx 支持 Win7+，只依赖
     游戏自带 Mono，不需装 .NET 或 VC++），但未实机验证。
   · Windows 10 32 位 / Win7：游戏本身不支持，与本补丁无关。
   · 英文版/精简版 Windows：自动用内置思源黑体子集；连它也被
     删掉时保持英文界面，不会出现方块。
   · 路径含中文或空格：脚本全程加引号，判断可用但未实测；
     装完没反应时优先换纯英文路径再试。
   · Linux / Steam Deck：未验证，不保证。

3) 权限与杀毒软件
   · 没有写入权限（Program Files 等）：按第二节用管理员运行。
   · 报毒/拦截：winhttp.dll 是 BepInEx 注入器，Mod 圈通行做法，
     行为像木马所以常被误报。加白名单，或在隔离区“恢复并信任”。
     最坏是文件被删，游戏变回英文，不坏档、不崩。
   · 本补丁不联网、不写注册表、不收集任何信息。

4) 已经装了别的 BepInEx Mod
   · 是本汉化（有 plugins\PigfaceCN\PigfaceCN.dll）：就地更新。
   · 是别人的 Mod：安装直接停止，不覆盖、不混合。
   · 想共存：手动把 plugins\PigfaceCN 放进现有 BepInEx\plugins。

5) Steam 更新与“验证文件完整性”
   · 更新：补丁文件不会被删。小更新照常可用（新句子显示英文）；
     中等更新可能个别错位；大更新（换引擎/转 IL2CPP）整体失效。
   · 验证完整性：不影响。BepInEx 不在 Steam 清单里，不会被删、
     不会被判损坏，验完照样是中文。
   · 任何情况下都不会把游戏改坏——补丁只做内存替换。

6) 封号与存档
   · 不会被封。纯单机，无 Easy Anti-Cheat、无 BattlEye、无 VAC、
     不联网校验，且不改可执行文件与资源包。
   · 存档不碰，位置仍是 %USERPROFILE%\AppData\LocalLow\
     titolovesyou\PIGFACE\，与英文版共用同一个档。

7) 装了还是英文 / 显示异常（三步排查）
   ① 看 BepInEx\LogOutput.log 是否有：
        dict loaded: 938 entries
        frag loaded: 131 entries
        font: simhei.ttf
        harmony patched ok
   ② 出现 font: NONE -> translation disabled：没找到中文字体，
      把 BepInEx\PigfaceCN\font.ttf 放回去；
      连日志都没有：注入没成功，多半杀软删了 winhttp.dll。
   ③ 方块 = 字体没加载；超框/断行难看 = 中英长度差异，
      属已知美术瑕疵，可在词库里手动加换行。

8) 性能
   只在界面元素变化时替换，新面板 0.35 秒内完成，平时只做一次
   很轻的检查。实测无明显帧数影响。
