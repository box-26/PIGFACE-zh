一、这是什么
----------------------------------------------------------------
Steam 版《PIGFACE》的中文补丁。装好后菜单、选项、任务目标、
对白、便条、手机、商店、制作站全部显示中文。

不改游戏本体（exe / data.unity3d / dll 一律不动），只新增一个
BepInEx 文件夹；文字、字体和一张“售罄”贴图在运行时于内存替换，
卸载即还原。


二、安装
----------------------------------------------------------------
  1. 解压到任意位置（别在压缩包里直接双击）。
  2. 双击“安装汉化.bat”。
  3. 脚本自动找游戏，找不到才请你粘贴路径。
  4. 看到“安装成功”即可，之后从 Steam 正常启动。

  装在 C:\Program Files 这类目录会一闪而过：改右键“安装汉化.bat”
  → 以管理员身份运行。

  升级：解压新包、再双击一次即可就地覆盖，不用先卸载。存档、
  按键设置、云同步都不受影响；检测到别人的 Mod 会停下，不混装。


三、卸载
----------------------------------------------------------------
双击“卸载汉化.bat”。文件被移到 %TEMP%\PIGFACE_CN_removed_<时间>，
不硬删，确认正常后自行删除。本体从未被改，无残留。


四、使用中的各种情况
----------------------------------------------------------------
1) 中文会晚一步出现，正常
   第一眼常是英文，0.2～1 秒后变中文；新开面板约 0.35 秒。手机
   面板由游戏每帧重写，个别数值会轻微跳动。
   ★ 等 2 秒仍是英文才算漏词：双击“检查缺词.bat”，把生成的
     “缺词报告.txt”发到 Issue 即可。

2) 系统与环境
   · Win11 23H2 实机、Win10 64 位虚拟机：已验证。
   · 只依赖游戏自带 Mono，不用另装 .NET / VC++。
   · Win10 32 位、Win7：游戏本身不支持。
   · 英文版/精简版系统：自动用内置思源黑体；它也没了则保持英文，
     不会出方块。
   · 路径含中文或空格：脚本已加引号，但未实测，没反应就换英文路径。
   · Linux / Steam Deck：未验证。

3) 权限与杀毒
   · 没写权限（Program Files 等）：按第二节用管理员运行。
   · 报毒：winhttp.dll 是 BepInEx 注入器，Mod 圈通行做法，行为像
     木马所以常被误报。加白名单，或从隔离区“恢复并信任”。最坏是
     文件被删、游戏退回英文，不坏档、不崩。
   · 不联网、不写注册表、不收集信息。

4) 已装别的 BepInEx Mod
   · 是本汉化：就地更新。
   · 是别人的：安装停止，不覆盖。
   · 想共存：手动把 plugins\PigfaceCN 放进现有 BepInEx\plugins。

5) Steam 更新与“验证文件完整性”
   · 更新：补丁不被删。小更新照常用（新句子显示英文）；中等更新
     可能个别错位；大更新（换引擎 / IL2CPP）整体失效。
   · 验证完整性：不影响，验完照样中文。
   · 任何情况都不会改坏游戏——只做内存替换。

6) 封号与存档
   · 不会被封：纯单机，无 EAC / BattlEye / VAC，不改 exe 与资源包。
   · 存档不碰，仍在 %USERPROFILE%\AppData\LocalLow\
     titolovesyou\PIGFACE\，与英文版共用同一个档。

7) 装了还是英文 / 显示异常
   ① 看 BepInEx\LogOutput.log 是否有：
        dict loaded: 965 entries
        frag loaded: 131 entries
        font: simhei.ttf
        harmony patched ok
   ② font: NONE -> translation disabled：没找到中文字体，把
      BepInEx\PigfaceCN\font.ttf 放回去。
      连日志都没有：注入没成功，多半杀软删了 winhttp.dll。
   ③ 方块 = 字体没加载；超框或断行难看 = 中英长度差异，属已知
      美术瑕疵，可在词库手动加换行。

8) 低分辨率下文字发虚
   原版如此：字号不变，但屏幕像素少了，每个字分到的像素变少，
   笔画糊在一起。汉化沿用原字号与渲染方式，不改变这点；调回
   1920×1080 或更高即可。
