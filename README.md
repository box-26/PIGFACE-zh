# PIGFACE 简体中文汉化

给 Steam 游戏 **《PIGFACE》**（AppID `3341650`）用的简体中文汉化补丁，基于 BepInEx 运行时替换。

- **不改游戏本体**：不改 `Pigface.exe`、不改 `data.unity3d`、不改任何 DLL，游戏文件哈希与 Steam 原版逐字节一致。
- **随时可卸载**：补丁就是游戏目录里一个 `BepInEx` 文件夹，卸载脚本把它挪走即可。
- **跟得上更新**：游戏小更新后照常可用（新出现的句子显示英文），不像静态改包那样整包失效。
- **开源**：代码 MIT，译文 CC BY-NC-SA 4.0，欢迎 Fork 自行维护。

> 本项目与游戏开发者、发行商无关，不包含任何游戏文件。请先购买正版。
> 代码、译文与贴图全部由 AI 生成，人类只负责提需求、试玩、报错。

## 下载与安装

到 [Releases](../../releases) 下载最新的 `PIGFACE-汉化-vX.Y.zip`。

1. 解压到任意位置（**不要**解压进游戏目录）。
2. 双击 `安装汉化.bat`。
3. 脚本会自动到 Steam 库里找 PIGFACE；找不到时按提示粘贴游戏路径
   （Steam 库 → 右键游戏 → 管理 → 浏览本地文件，复制地址栏）。
4. 看到「安装成功」后，从 Steam 正常启动游戏。

装在 `C:\Program Files` 这类目录时需要管理员权限：右键 `安装汉化.bat` → 以管理员身份运行。

**升级**：装过旧版的话，解压新包重新双击 `安装汉化.bat` 即可就地覆盖，不用先卸载。
存档、按键设置、Steam 云同步都不受影响。

**卸载**：双击 `卸载汉化.bat`，文件会被移到 `%TEMP%\PIGFACE_CN_removed_<时间>`，不硬删。

## 覆盖范围

**已汉化**：主菜单、选项、操作说明、制作人员、任务目标与任务简报、对白与字幕、
便条与手写笔记、手机面板、商店、制作站、世界地图、结算界面，以及界面上的 `SOLD OUT` 贴图。

**保持英文**：版本号、分辨率数值、`SSAO`/`FPS` 之类技术缩写、枪械型号（`M870`、`AK47` 等），
以及部分**运行时拼接**的边角文本（过场字幕、成就提示）——这类句子可能仍有漏网。

漏掉的句子会自动写进 `BepInEx\PigfaceCN\miss.log`，把该文件发到 issue 就能定位补译。

## 中文显示

- 优先使用系统中的中文字体（黑体 / 微软雅黑 / 宋体 / 等线）。
- 系统没有中文字体时，自动使用包内的思源黑体子集（约 470 KB，SIL OFL 1.1）。
- 连内置字体都加载失败时**自动退回英文界面**，不会出现满屏方块。

## 工作原理

| 替换对象 | 做法 |
| --- | --- |
| 文本 | Harmony 钩住 `TMP_Text.set_text` / `SetText` / `UI.Text.set_text`，命中词典就换成中文；另有定时扫描兜底 |
| 字体 | 运行时 `FontEngine.LoadFontFace(路径)` 读系统字体或包内 `font.ttf`，手工烘 SDF 图集构造 `TMP_FontAsset` |
| 贴图 | 只替换商店那张 `SOLD OUT`（256×128）为「售罄」，沿用原 sprite 的 pivot / PPU / border |

全部发生在内存里，**不写游戏目录的任何文件**。细节见 [docs/architecture.md](docs/architecture.md)。

## 已知问题

- 中文会比英文晚 0.2–1 秒出现（运行时替换的固有代价）。
- 手机面板由游戏每帧重写，个别数值偶有轻微跳动。
- 与其它 BepInEx 插件共存未验证；安装脚本检测到别人的 Mod 会中止，不会覆盖。
- `winhttp.dll` 是 BepInEx 的注入器，可能被杀毒软件误报。本补丁不联网、不写注册表。

## 参与维护

词库是纯文本，**不需要会编程也能改**：

```
dict/zh_master.tsv    一行一条：英文<TAB>中文
dict/frag_master.tsv  片段规则，用于只替换一句话里的某个词
```

改完跑 `python tools/check.py` 与 `python tools/build_dict.py` 即可验证。完整说明见
[CONTRIBUTING.md](CONTRIBUTING.md)。

**这个项目欢迎任何人接手维护**：Fork 之后自己改、自己发版即可，不需要作者同意，
也不必把改动合并回来（MIT 允许）。作者不在了，这份代码也照样能继续被维护。
