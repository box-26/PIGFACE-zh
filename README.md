# PIGFACE 简体中文汉化

给 Steam 游戏 **《PIGFACE》**（AppID `3341650`）用的简体中文汉化补丁，基于 BepInEx 运行时替换。

- **不改游戏本体**：`Pigface.exe`、`data.unity3d`、所有 DLL 逐字节保持原样。
- **随时可卸载**：补丁就是游戏目录里一个 `BepInEx` 文件夹，挪走即还原。
- **跟得上更新**：游戏小更新后照常可用（新句子显示英文），不像静态改包那样整包失效。
- **开源**：代码 MIT，译文 CC BY-NC-SA 4.0，欢迎 Fork 自行维护。

> 与游戏开发者、发行商无关，不包含任何游戏文件，请先购买正版。
> 代码、译文与贴图全部由 AI 生成，人类只负责提需求、试玩、报错。

## 下载与安装

到 [Releases](../../releases) 下载最新的 `PIGFACE-zh-vX.Y.zip`。

1. 解压到任意位置（**不要**解压进游戏目录）。
2. 双击 `安装汉化.bat`。
3. 脚本自动找游戏：只有一份就直接装；多份时列出编号让你选（可输入 `1,2` 一次装多份）；一份都没有才请你粘贴路径。
4. 看到"安装成功"后，从 Steam 正常启动。

装在 `C:\Program Files` 这类目录需要管理员权限：右键 `安装汉化.bat` → 以管理员身份运行。

**升级**：解压新包、再双击一次即可就地覆盖，不用先卸载；存档、按键设置、云同步不受影响。

**卸载**：双击 `卸载汉化.bat`，文件移到 `%TEMP%\PIGFACE_CN_removed_<时间>`，不硬删。

## 来源与校验

官方发布只有 GitHub Releases 一处：<https://github.com/box-26/PIGFACE-zh/releases>

每个 Release 的正文里都写有对应 zip 的 SHA256。想核对，在压缩包所在目录运行：

```bat
certutil -hashfile PIGFACE-zh-vX.Y.zip SHA256
```

算出来的值与发布页一致，才算文件没被改过。网盘、论坛、群文件里的包可能被替换或重新打包，作者无法保证其内容。

## 覆盖范围

**已汉化**：主菜单、选项、操作说明、制作人员、任务目标与简报、对白与字幕、便条与手写笔记、手机面板、商店、制作站、世界地图、结算界面，以及界面上的 `SOLD OUT` 贴图。

**保持英文**：版本号、分辨率数值、`SSAO`/`FPS` 等技术缩写，以及少数运行时拼接的边角文本——这类句子可能仍有漏网。

漏掉的句子会自动写进 `BepInEx\PigfaceCN\miss.log`。玩家侧双击 `检查缺词.bat`，它会整理成 `缺词报告.txt`（带系统版本、游戏 build、字体与界面位置，不含用户名和完整路径），发到 Issue 即可。

## 中文显示

- 优先用系统中文字体（黑体 / 微软雅黑 / 宋体 / 等线）。
- 系统没有时用包内思源黑体子集（约 470 KB，SIL OFL 1.1）。
- 内置字体也加载失败时**自动退回英文界面**，不会满屏方块。

## 工作原理

| 替换对象 | 做法 |
| --- | --- |
| 文本 | Harmony 钩住 `TMP_Text.set_text` / `SetText` / `UI.Text.set_text`，命中词典即替换；另有定时扫描兜底 |
| 字体 | 运行时 `FontEngine.LoadFontFace(路径)` 读系统字体或包内 `font.ttf`，手工烘 SDF 图集构造 `TMP_FontAsset` |
| 贴图 | 只替换商店那张 `SOLD OUT`（256×128）为"售罄"，沿用原 sprite 的 pivot / PPU / border |

全部发生在内存里，**不写游戏目录的任何文件**。细节见 [docs/architecture.md](docs/architecture.md)。

## 已知问题

- 中文比英文晚 0.2–1 秒出现（运行时替换的固有代价）；手机面板个别数值偶有跳动。
- 与其它 BepInEx 插件共存未验证；安装脚本检测到别人的 Mod 会中止，不覆盖。
- `winhttp.dll` 是 BepInEx 注入器，可能被杀软误报；补丁不联网、不写注册表。
- 低分辨率下文字发虚是原版问题，与汉化无关。

## 参与维护

词库是纯文本，**不需要会编程**：

```
dict/zh_master.tsv    一行一条：英文<TAB>中文
dict/frag_master.tsv  片段规则，只替换一句话里的某个词
1-收集漏词.bat        读 miss.log，生成 待翻译.tsv（自动剔除人名与技术串）
2-应用译文.bat        写回词库、重建词库并检查字体缺字
```

改完跑 `python tools/check.py` 验证。完整说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。
